# Code of conduct

This project is a place for useful technical work. Everyone who takes part follows these rules.

## Expected behaviour

- Be respectful and assume good faith.
- Give feedback on the work, not the person.
- Accept feedback and credit others for their ideas.
- Keep discussion on topic.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Discrimination of any kind.
- Publishing private information without consent.
- Spam or deliberate disruption.

## Enforcement

The maintainers remove content and restrict access when someone breaks these rules. To report a problem, use the private report route in GitHub. Open the **Security** tab, click **Report a vulnerability**, and say it is a conduct report. Only the maintainers see it.
