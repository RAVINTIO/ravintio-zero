# Security policy

## Supported versions

Only the latest release receives security fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting. Do not open a public issue for a vulnerability.

1. Open the **Security** tab of the repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

You can also use the direct link: <https://github.com/RAVINTIO/ravintio-zero/security/advisories/new>.

## What to include

- The affected file, hook, or skill.
- The version or commit you tested.
- Steps to reproduce the problem.
- The impact you expect.
- A proposed fix, if you have one.

## What to expect

The maintainers acknowledge your report within 5 working days. They then share a plan for the fix and credit you in the release notes if you wish.
