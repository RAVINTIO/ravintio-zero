# Domain Glossary - Test helpers and rule anchors

**Skill:** [plan](../../ravintio-zero/skills/ravintio-plan/SKILL.md)
**Feature:** 0000380-test-helpers-and-rule-anchors
**Version:** 0.60.0

## Terms

| Term | Definition | Aliases | Used In |
|------|-----------|---------|---------|
| Rule anchor | An HTML comment `<!-- rule: {id} -->` placed before a rule. It gives the rule a stable name. | anchor | ravintio-zero |
| Rule id | The lowercase letters, digits, and hyphens in an anchor. Each id is unique across the pack. | anchor id | ravintio-zero |
| Key term | A word or phrase a test requires in a rule's text. | pinned term | ravintio-zero |
| Section | The text from a heading to the next heading of the same or higher level. | none | ravintio-zero |
