# Domain Glossary - Plan checks

**Skill:** [plan](../skills/ravintio-plan/SKILL.md)
**Feature:** 0000384-plan-checks
**Version:** 0.63.0

## Terms

| Term | Definition | Aliases | Used In |
|------|-----------|---------|---------|
| ADR number | A repo-wide four-digit number that names one ADR file in `docs/adr/` | none | ravintio-zero |
| Living docs unit | A unit in the Concurrency plan that writes the files under `docs/` that the run changes | none | ravintio-zero |
| Shared resource | A runtime resource that two units can contend for, such as a port, a build folder, or a lock file | none | ravintio-zero |
| Human-only setting | A repository setting that only a human can change, which a chart row names | none | ravintio-zero |
| Oldest shell line | The `Oldest shell:` line in an ADR that names the oldest shell the decision must run on | none | ravintio-zero |
