# Changelog (0000385-faster-test-runs, 07 Nov 2026)

**Feature:** Faster test runs
**Version:** set by the merge queue at merge
**PR:** see the step PR

## What changed

- A TDD cycle runs the new test and the tests that cover the changed files. One full suite runs in the background before P2 completes. Each cycle logs a `Tests run:` line (0000294).
- `scripts/baseline-failures.mjs` records the suites that fail on the base commit at P0 and compares them at P3. P3 stops only on a new suite, and ship lists the inherited ones (0000295).
- `scripts/clean-clone-test.mjs` runs the suite in a clean clone of `HEAD`, names an OS gap, and removes the clone. P3 uses it (0000296).
- `testing-standards.md`, the tests README, `component.yml`, and the architecture overview describe the changes.

## Why

Six retrospectives record that suite runs took most of P2's wall clock. Inherited failures and local state made P3 results differ from CI.
