# Changelog (0000442-ready-file-helper, 10 Nov 2026)

**Feature:** Ready file helper
**Version:** set by the merge queue at merge
**PR:** pending

## What changed

- New script `initiative-ready.mjs`. `--pr {n}` checks the number and writes `$RAVINTIO_INITIATIVE_CONTROL/ready`. `--check` reports whether the file holds a PR number.
- The driver recovers a bad `ready` file. If the file is empty or invalid, it asks `gh` for the one open PR of `feat/{feature-id}`, rewrites the file, and queues the step. With no single PR it stops as before.
- The ship skill, the roadmap standards, the component manifest, and the architecture overview name the helper.
- ADR 0301 records the decision.

## Why

Step 9 wrote a timestamp and step 20 left the file empty. The driver stops on any value that is not a PR number. Backlog entry 0000424 asked for a helper and a recovery path.

## Deviations

- P2 ran inline without subagents, because the three units depend on each other.
- The 0000379 queue handoff test now sets `RAVINTIO_GH_BIN=false` in its bad-file case, so it never calls the real `gh`.
