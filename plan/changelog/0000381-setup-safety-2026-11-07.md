# Changelog (0000381-setup-safety, 07 Nov 2026)

**Feature:** Setup safety
**Version:** set by the merge queue at merge
**PR:** #131

## What changed

- Setup writes `.ravintio-manifest` paths relative to the repo root. It removes a listed folder only if it sits directly inside the skills directory, and it skips and warns about any other line (0000262).
- The test runners list `.claude/skills/` before and after a run and fail on a difference.
- Setup copies each capability skill folder in full, with `references/`, `scripts/`, and `assets/` (0000289).
- A first install moves a developer's own `CLAUDE.md` content to `ravintio-overrides/instructions/original-CLAUDE.md` and prints the path (0000290).
- Setup prunes commands the pack no longer ships, through `.claude/commands/.ravintio-manifest` and a retired list. Migration 0008 and its helpers do the same outside setup (0000293).
- All changes are in `setup.sh` and `setup.ps1`, with paired suites.

## Why

Setup could delete files outside its skills directory, skipped files in capability skills, overwrote a developer's `CLAUDE.md`, and left commands that contradict the pipeline.
