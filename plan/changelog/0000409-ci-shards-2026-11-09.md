# Changelog (0000409-ci-shards, 09 Nov 2026)

**Feature:** Sharded CI suites
**Version:** no bump. This PR is not a chart step of initiative 0000360.
**PR:** #144

## What changed

- `run-tests.sh` and `run-tests.ps1` read `RAVINTIO_SHARD=i/n` and run only shard i of n. A malformed value exits 2.
- CI runs `bash-suites-shard` in 4 shards and `windows-powershell-shard` under Windows PowerShell 5.1 in 4 shards, all in parallel.
- Two summary jobs, `bash-suites` and `windows-powershell (powershell)`, carry the required check names. Each passes only when every shard passed.
- CI no longer runs the suites under pwsh on Windows. pwsh still runs every `.ps1` suite on Linux.
- ADR-0284 supersedes ADR-0126. The three CI-shape tests, `tests/README.md`, and the architecture overview describe the new jobs.

## Why

On 2026-11-09 the slowest required check took about 16 minutes, and every merge-queue run waits for it. The human asked to speed up CI and chose to shard and drop the Windows pwsh run.

## Deviations

- P2 ran inline without subagents, because the two units share the workflow file.
- The design named 3 Windows shards. The first CI run took 7m23s on one of them, over the 7-minute target, so CI now runs 4.

## Validation results

- Suites: 362 of 364 passed in a clean clone, run in 4 local shards. `test-0000037-req-004` and `test-0000318-req-004` also fail on the base commit.
- CI on PR #144 passed in 4 minutes 40 seconds. The slowest shard took 4.5 minutes, against about 16 minutes before.
- Security review: no critical or high finding.
