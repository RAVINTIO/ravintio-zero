## What changed

- Moved the pack source from `ravintio-zero/` to `src/ravintio-zero/` in a pure rename, so `git log --follow` keeps history.
- Added `ravintio-zero/` as a plain installed copy of the source. Hooks, the driver, and skills run that copy.
- Added `src/ravintio-zero/scripts/sync-installed.mjs`. It refreshes the copy. With `--check`, it compares the folders byte for byte.
- Retargeted tooling and tests so they run against either folder.
- Extended every guard that covers `ravintio-zero/` to cover `src/ravintio-zero/`.
- Wrote `src/ravintio-zero/docs/layout.md` and ADR 0295. Updated the living docs and the manifest.

## Why

A source edit changed the running pack at once. The repo could not develop the pack as a consumer uses it. Backlog entry 0000396 asked for the move.
