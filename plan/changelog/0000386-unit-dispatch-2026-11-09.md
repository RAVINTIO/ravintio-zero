# Changelog (0000386-unit-dispatch, 09 Nov 2026)

**Feature:** Unit dispatch
**Version:** set by the merge queue at merge
**PR:** pending

## What changed

- `ravintio-implement` gains an inline unit rule. A `content` unit that applies agreed text or changes one file runs the TDD loop in the main session. It logs `RED:` before `GREEN:`, dispatches no subagent, and skips the improvement loop.
- `build-log-check.mjs` reports a `GREEN:` marker with no earlier `RED:` marker, and an inline `Done:` line that lacks either marker.
- `agent-dispatch-standards.md` holds a table that maps a unit's class and three signals to a model tier and an effort level. The tier replaces the skill's `recommended_model` for that dispatch.
- The `Done:` line records `{class}, {tier}, {effort}`. `resume-detect.mjs` accepts the unit name `{REQ} inline`.
- `workflow-metrics.mjs` reports units and rework by class and tier.
- ADR-0285 records the decision. The architecture overview and the decisions index describe it.

## Why

Backlog entries 0000330 and 0000366. Content units ran inline and logged a departure each time. Dispatch also picked one tier for a whole phase.
